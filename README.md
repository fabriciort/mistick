# Mistick Assessoria & Eventos

Site de cartão de visita online moderno e elegante para **Tina Ribéro** - Mistick Assessoria & Eventos.

## 🌟 Funcionalidades

- **Design Elegante**: Interface moderna com animações suaves usando GSAP e ScrollTrigger
- **Animações**: Efeitos de texto animado, parallax e transições fluidas
- **Integração WhatsApp**: Botão flutuante e formulário de contato integrado com WhatsApp
- **Responsivo**: Layout otimizado para desktop, tablet e mobile
- **Loader Animado**: Tela de carregamento com animação da marca
- **SEO Otimizado**: Meta tags configuradas para melhor indexação

## 🎨 Paleta de Cores

- **Cream**: `#FAF6F1` - Background principal
- **Cream Dark**: `#F0E9E0` - Background secundário
- **Forest**: `#2C3E3E` - Cor principal de texto
- **Gold**: `#C4813A` - Cor de destaque/accent

## 🛠️ Tecnologias

- **React 19** - Framework JavaScript
- **Vite** - Build tool e dev server
- **Tailwind CSS** - Estilização utilitária
- **GSAP** - Animações avançadas
- **ScrollTrigger** - Animações baseadas em scroll

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## 📱 Seções do Site

1. **Hero** - Apresentação da marca com animações
2. **Sobre** - Informações sobre Tina Ribéro e a empresa
3. **Serviços** - Casamentos, Festas, Consultoria, Eventos Corporativos
4. **Contato** - Formulário integrado com WhatsApp

## ⚙️ Configuração

### WhatsApp

Para configurar o número do WhatsApp, edite o arquivo:

```javascript
// src/utils/whatsapp.js
const WHATSAPP_NUMBER = '5511999999999' // Substitua pelo número real
```

### Informações de Contato

Atualize as informações de contato no componente `Contact.jsx`:
- Número de telefone
- E-mail
- Localização
- Links das redes sociais

## 🚀 Deploy

O projeto está pronto para deploy em plataformas como:
- Vercel
- Netlify
- GitHub Pages

```bash

npm run build
```
